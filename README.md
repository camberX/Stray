# Stray

A Hypixel SkyBlock client written by asking an AI to keep going.

The point is to see how far vibe coding can get: click GUI, ESP, mining and farming HUDs, capes, media, the shop at [stray.gay](https://stray.gay). Almost none of it was typed by hand.

Get the jar for your version (Minecraft 26.3 or 26.2) from [stray.gay](https://stray.gay) and drop it into `mods` with Fabric Loader and Fabric API. Right Shift opens the menu. 26.1.2 is no longer updated.

```bash
./gradlew build   # builds every version under versions/ with Stonecutter
```
