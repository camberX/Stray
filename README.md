# Stray CS2 knife data

Counter-Strike 2 knife models, textures and animations used by Stray's CS2 knives feature,
packed into `cs2.pack` and split into parts under GitHub's file size limit. The mod downloads
them once (see `cs2.json`) and checks the SHA-256 before using them.
