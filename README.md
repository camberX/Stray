# Stray

A Hypixel SkyBlock client written by asking an AI to keep going.

The point is to see how far vibe coding can get: click GUI, ESP, mining and farming HUDs, capes, media, the shop at [stray.gay](https://stray.gay). Almost none of it was typed by hand.

Drop the jar from [stray.gay](https://stray.gay) into `mods` with Fabric Loader, Fabric API, and Minecraft 26.1.2. Right Shift opens the menu.

```bash
./gradlew build
```
